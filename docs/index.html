Features

Everything you need. Nothing you rent.

One binary covers the full daily workflow — from first connection to ER diagram to SQL dump.

🔌

Connections & picker

Saved profiles with test-connection, latency + server version. Leave the database empty to land on the postgres maintenance DB, then switch databases without reconnecting.

🗂

Schema explorer

Schemas, tables, views, matviews & foreign tables with filters, row estimates, sizes, lock icons for missing privileges — per-schema failures never wipe the tree.

✏️

Data editing, PK-optional

Paginated grid with 3-state sort, multi-select bulk delete, and ctid-addressed editing that works even without primary keys. NULL / DEFAULT / Value modes per column.

🧱

Structure (DDL) editing

Create tables, add / rename / retype columns, manage NOT NULL & defaults, drop columns & tables — all privilege-gated, identifiers safely quoted.

🕸

Interactive ER diagram

Pan / zoom / drag-to-arrange canvas with 4 auto-layouts, search across tables and columns, isolate, SVG export and Mermaid copy.

⚡

Multi-statement SQL

Quote- and dollar-quote-aware batch runner with per-statement tabs, timing, history, persisted queries and BOM-correct CSV export.

📥

CSV import & export

RFC-4180 import with header or positional mapping, preview and chunked 500-row batches — plus one-click table export up to 50k rows.

💾

SQL dump & restore

Logical .sql dumps (DDL + parents-first INSERTs, views last) per database or per table, with chunked, progress-tracked restore.

👥

Role manager

Create / edit / drop LOGIN roles, manage memberships, connection limits and expiry — read-only pill for non-superusers, server-side enforcement.

🖥

Server overview

Version, database size, table count, connections and uptime at a glance.

🛡

Privilege-aware UI

Every button is gated up front by real GRANT checks — and the server still says no to bypass attempts (covered by a readonly-role test).

🌐

Web preview

Try it in the browser with built-in mock data — zero install, zero database. The desktop build swaps in the live Rust backend.

🪶

Featherweight by design

The native Rust backend averages under 10 MB RAM and idles near 0% CPU. No bundled Chromium, no JVM — your database gets the resources, not the tool. Heavy jobs (CSV import, dumps) stream in small batches so the UI never stutters.

Install notes
  • Windows: run the -setup.exe installer, or just launch the portable postiexplorer.exe (WebView2 is preinstalled on Win10/11).
  • Linux: chmod +x PostiExplorer_amd64.AppImage && ./PostiExplorer_amd64.AppImage — or sudo dpkg -i PostiExplorer_amd64.deb.
  • macOS (Apple Silicon): open the .dmg and drag PostiExplorer to Applications. No Intel build yet — build from source or vote in the issues.
  • File names carry no version on purpose, so these links never break. The running app shows its version in the header.

Architecture — where code goes

  • All SQL lives in src-tauri/src/db.rs; main.rs commands are thin wrappers.
  • New feature = function in db.rs → #[tauri::command] → call in src/lib/api.ts.
  • src/types.ts mirrors src-tauri/src/models.rs — change both.
  • Browser fallback via src/lib/mock.ts must never break npm run dev.

FAQ

Questions, answered.

Is PostiExplorer really free?

Yes — MIT licensed, no paywall, no account, no telemetry. Binaries are built in public by GitHub Actions on every push to main.

Which platforms are supported?

Windows x64 (+ ARM64 installer), Linux x64 (AppImage + .deb) and macOS Apple Silicon (.dmg). The site auto-detects your OS and picks the right file.

Do I need to install PostgreSQL first?

No — but you need a server to connect to. For local dev, docker compose up -d starts a seeded postgres:16. You can also click around the browser preview with mock data first.

Can I edit tables without a primary key?

Yes. Row edits are addressed by PostgreSQL's internal ctid, so insert / update / delete work even on PK-less tables. Views and matviews stay read-only.

Is my connection secure?

Connections are direct from your machine to your database — no cloud in between. Note: sslmode=require is currently accepted but the backend still uses plaintext (NoTls); real TLS is on the roadmap. Don't expose dev databases to the internet.

How light is it, really?

Very: the native Rust backend averages under 10 MB RAM and idles near 0% CPU, and Tauri uses your OS webview instead of bundling Chromium — so there's no 200 MB runtime tax like Electron apps pay. (Total app memory also includes the system WebView itself, which the OS manages and shares with other apps.)

How do I update?

Download links are versionless and always point at the newest CI build — just grab the file again. Installers carry the version internally for upgrade detection.
